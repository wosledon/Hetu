桌面应用

桌面版是 Tauri 2 外壳：Rust 进程负责窗口、托盘与更新，同时把打包好的后端（sidecar）拉起来，前端跑在 WebView 里。不想配 .NET / Node 环境就用它。

安装

渠道产物依赖
fatHetu_x.y.z_x64-setup.exe / .msi无（自带 .NET 运行时，约 100 MB+）
slimHetu.Slim._x.y.z_x64-setup.exe / .msi系统已安装 .NET 10 运行时
Linux.AppImage / .debAppImage 免安装

两个渠道各自独立更新，互不覆盖：装的是 slim 就只会收到 slim 的更新清单。

自动更新

  • 检查顺序：GitHub 主源 → 三个加速镜像（ghproxy.net / gh-proxy.com / ghfast.top），国内网络下也能拉到清单。
  • 更新包装好后按 passive 模式安装；清单里的安装包 URL 与签名都来自 CI 构建，签名校验失败会拒绝安装。
  • 导航栏版本号旁的角标提示有更新，点开可以看到本次更新内容（按 Markdown 渲染）。

托盘与退出

  • 点击窗口关闭按钮默认最小化到托盘，后端继续运行——后台索引、Wiki 生成这类任务不会被打断。
  • 托盘菜单「退出 Hetu」才是真正退出，会一并结束后端子进程。
  • 不想要这个行为：设置 → 应用设置 → 关闭「关闭时最小化到托盘」。
后端会记住外壳的进程号（HETU_PARENT_PID）：万一外壳被任务管理器强杀，后端检测到父进程消失会自行退出，不会留下占端口的孤儿进程。

工作树目录与自动清理

  • 默认把所有工作树收在仓库父目录下的 .hetu-worktrees/<仓库名>/<工作树名>，父目录只多这一个文件夹。
  • 可在 设置 → 工作区 改成别的根目录（必须是绝对路径，且不能落在仓库内部）。
  • 自动清理：工作树里的改动都已合并、没有未提交内容、且空闲超过阈值时，后台按配置的间隔清理；可以配置间隔、空闲时长，以及是否连分支一起删。

数据放在哪

外壳通过 HETU_DATA_DIR 把数据目录交给后端：Windows 上是 %LOCALAPPDATA%\Hetu，数据库文件 hetu.db（外加 WAL），日志在 logs/。迁移机器时把整个目录拷走即可。

自己打包

# 1) 先出后端 sidecar（fat / slim 二选一）
pwsh ./scripts/publish-backend.ps1 -Mode SelfContained      -Rid win-x64
pwsh ./scripts/publish-backend.ps1 -Mode FrameworkDependent -Rid win-x64

# 2) 再出安装包（fat 用默认配置，slim 指定 conf）
cd shell/hetu-desktop
npm run tauri:build
npm run tauri:build -- --config src-tauri/tauri.slim.conf.json

sidecar 命名必须符合 Tauri 约定：binaries/Hetu.Api-<rust-target-triple>(.exe)。

更新之后的权限提升

更新是替换式安装：安装包在覆盖文件前会先结束残留的后端进程（安装钩子），所以即使上一次异常退出过也能顺利升级。
