常见问题

按主题整理的高频问题。遇到这里没写的，可以在 GitHub 提 Issue（附上日志片段与复现步骤，会快很多）。

安装与启动

桌面版安装报 “Error opening file for writing: …vec0.dll”

上一次运行留下了没退干净的后端进程，它加载着 sqlite-vec\vec0.dll，安装器覆盖不了。处理：任务管理器结束所有 Hetu.Api.exe，然后点「重试」；新版本的安装包已经内置安装钩子，会在覆盖前自动清理残留进程。

源码运行前端打不开 5174

  • 确认后端已在 5000 起：curl http://localhost:5000/api/health。
  • 前端首次运行要先 npm install；端口被占时 Vite 会自动换端口，注意看终端输出。

模型与 Key

能只用本地模型吗

可以——任何暴露 OpenAI 兼容接口的本地推理服务（Ollama、LM Studio、vLLM 等）都能作为供应商加进来，填本地 Base URL 即可。Embedding 也用本地模型的话，注意把维度与 Embedding:Dimensions 对齐。

为什么 Anthropic 不能做 Embedding

Anthropic 没有公开 Embedding 接口。把 embedding 用途指到 OpenAI 兼容供应商即可。

Key 存在哪里，安全吗

加密后存在本地数据库里（Windows 用 DPAPI 保护），不会明文出现在日志或接口响应；详见 数据与备份。

知识与索引

索引卡住 / 覆盖率上不去

  • 先看「后台任务」页是否有失败记录（失败原因通常写在任务详情里）。
  • 检查 Embedding 供应商是否可用：知识库 → 搜索测试，随便问一句看是否返回命中。
  • 维度不匹配（换过 Embedding 模型）会写入失败，需要重新索引。

语义搜索搜不到我想要的

  • 先确认内容确实已索引（索引管理里看该项分块数）。
  • 换更具体的问法；在「搜索测试」里调 Top-K 看不同召回。
  • 笔记类内容建议先「生成索引」再依赖检索。

Code 会话与工作树

工作树是什么，会污染我的仓库吗

工作树是 git worktree 创建的独立目录（默认在仓库父目录的 .hetu-worktrees/ 下），有自己的分支与工作区，主仓库目录不受影响。改动合并后可让自动清理回收。

会话标题旁的分支不一样了 / 想换分支

会话开始后工作区与分支就固定了，避免中途换环境导致改动错位；需要换环境请新建会话，或在「Git」面板里操作分支。

PR 面板说找不到 gh / glab

PR 功能复用你机器上的 GitHub CLI 或 GitLab CLI。面板会按平台给出安装命令（如 winget install --id GitHub.cli），装完点刷新即可。

更新

点更新报 “Could not fetch a valid release JSON from the remote”

这是更新清单没取到（旧版本曾出现清单命名与渠道不匹配）。请升级到最新版本；若仍失败，可用浏览器直接打开更新地址确认能访问：https://github.com/wosledon/Hetu/releases/latest/download/latest.json（slim 渠道是 latest-slim.json）。

托盘图标点了没反应

窗口可能被最小化到托盘后又移到了副屏。先点托盘图标唤回窗口；实在不行任务管理器结束后端进程重启应用。

性能

数据多了会不会变慢

列表接口分页在数据库侧完成（SQL COUNT + OFFSET/FETCH），知识库状态与向量摘要走数据库聚合，列表类只读接口还带短时响应缓存，数据量上万级也不至于把整表读进内存。

能不能离线用

应用本体完全离线可用；只有你显式使用云端模型、联网搜索或 MCP 服务时才需要网络。
