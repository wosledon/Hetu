Agent 工作台

入口是左侧导航「Code」（路由 /code）。对话与编码会话在同一界面：左侧是分组 / 话题 / 会话树，右侧是消息流；/chat 与 /work 都重定向到这里。

点图看原图

会话与话题

概念说明
会话组话题的容器，用于分区（如按主题或项目分组）
话题独立模型、系统提示、上下文窗口与历史；可对某条消息分叉成新话题继续探索
懒创建新建会话 / 话题只占位，不写库；发出第一条消息才真正创建（标题取消息前 50 字）
消息操作复制、编辑后重发、删除；思考过程可折叠；长回复支持复制 Markdown 原文

流式事件

回复通过 SSE 推送，界面按事件类型分区渲染：

事件界面表现
delta正文增量输出
thinking可折叠的思考轨迹（开启深度思考时）
工具调用 / 结果工具名、参数、输出摘要，可展开看完整内容
联网搜索 / 知识库 / 记忆命中列表（标题 + 片段），点开可跳转来源
待办清单模型输出的计划（todo 工具）实时勾选
steering运行中引导被接受时显示提示条
检查点任务开始前的文件快照记录
审批请求需要确认的高风险操作，就地批准 / 拒绝

输入工具带

控件作用与细节
联网搜索先做查询改写再检索，结果作为上下文注入并给出引用列表
知识库向量召回已索引的笔记 / 文件 / 网址
记忆召回长期记忆；作用域为「全局 ∪ 当前会话 ∪ 当前项目」
权限模式计划 / 只读 / 询问 / 自动 / 绕过（见下表）
模型本次请求临时换模型
智能体套用某个系统提示预设（可带工具白名单与审批策略）
推理强度低 / 中 / 高，影响思考与工具调用深度
/ 技能菜单输入 / 唤起技能或智能体
附件图片（视觉模型多模态）与文件；超长粘贴自动折叠成块

权限模式

模式允许的动作
plan 计划只规划与讨论，不改文件、不跑有副作用的命令
readonly 只读可读文件、执行只读命令
ask 询问（默认）每个写操作 / 敏感命令先请求批准
auto 自动常规操作直接执行，敏感操作仍询问
bypass 绕过全部放行，仅建议在隔离环境使用

Code 会话另有运行模式：交互式（逐步确认）与 Autopilot（托管执行到任务完成）。审批粒度可在「智能体」页按工具逐个配置。

队列与运行中引导

  • 队列：回复流式输出期间发送的消息进入队列条，可编辑、删除、立即发送，或在本轮结束后自动发出。
  • 引导（steering）：把一条指令立刻插进当前这一轮——Agent 会在下一次迭代时结合它调整后续动作，适合中途纠偏（「先别改那个文件」）。

上下文与压缩

  • 右下角环形指示当前上下文占用；接近阈值时可自动触发压缩，压缩后输入框上方给出提示条。
  • 压缩由「成本控制」里的管道配置驱动（何时压缩、压到多长、用哪个模型摘要），压缩前后的 Token 都会记入用量。

把话题变成笔记

「整理成笔记」支持四种风格：摘要、详细、问答、自定义提示；带流式预览，可指定目标笔记本后保存为正式笔记。
