Agent 工作台

入口是左侧导航的「Code」（路由 /code）。对话和编码会话在同一个界面：左边是分组 / 话题 / 会话树，右边是消息流与工作面板。

会话与话题

  • 话题：属于某个会话组，各自独立的模型、系统提示、上下文与历史；可以分叉一个话题做分支探索。
  • 懒创建：只占位不落库——没真正开始对话就不会产生新会话记录。
  • 消息操作：复制、编辑后重发、删除；长回复可折叠思考过程。
  • 上下文占用：右下角环形指示当前占用，压缩发生时在输入框上方给出提示。

输入工具带

控件作用
联网搜索检索网络并把结果作为上下文注入（带来源列表）
知识库从已索引的笔记 / 文件 / 网址中做向量召回
记忆召回长期记忆（可限定全局 / 当前会话 / 当前项目）
权限模式计划 / 只读 / 询问 / 自动 / 绕过
模型 / 智能体 / 推理强度本次请求用哪个模型、套哪个系统提示、思考多深
/ 技能菜单在输入框里直接唤起技能或智能体
附件图片（视觉模型多模态）与文件；超长粘贴自动折叠成块

权限模式与运行模式

模式行为
plan 计划只做规划与讨论，不动文件
readonly 只读可以读文件、跑只读命令，不写不改
ask 询问（默认）每个有副作用的操作都先请求批准
auto 自动常规操作直接执行，敏感操作仍会询问
bypass 绕过全部放行（仅建议在隔离环境/一次性任务里使用）

Code 会话另有运行模式：交互式（逐步确认）与 Autopilot（托管执行到完成）。审批规则可在「智能体」里按工具逐个配置。

队列与运行中引导

回复还在流式输出时，你可以继续打字：

  • 排队：新消息进入队列条，可编辑、删除，或等本轮结束后自动发出。
  • 引导（steer）：点「引导」把这条指令立刻插进当前这一轮，Agent 会在下一次迭代时结合它调整动作——适合「方向不对，先别改那个文件」这类场景。

Code 会话：在工作区里动手

项目与工作区

  • 项目支持本地目录与 SSH 远程仓库，可分组管理。
  • 每个会话二选一：在当前分支上工作（选分支即检出），或创建独立工作树（默认放在仓库父目录的 .hetu-worktrees/<仓库>/<工作树名>，可在设置里改根目录）。
  • 工作树在首条消息时按你的描述命名创建，主工作区不受影响；会话标题旁常驻工作区与分支徽标。
  • 分支选择器包含本地与远程分支（选远程会建本地跟踪分支）；标题旁一个同步按钮按状态自动决定拉取 / 推送 / 刷新。

七个工作面板

面板用途
文件浏览项目目录，搜索文件名与内容，内置编辑器可直接保存
更改本会话产生的文件改动，逐行 Diff 与回滚
检查点任务开始前的文件快照，可整体还原工作区
Git分支与工作区状态、逐文件 Diff、暂存并提交
PR按远端自动选用 gh / glab：当前分支 PR、开放 PR 列表、一键创建（含草稿）；未安装时给出对应平台安装命令
浏览器内嵌预览本地服务与网页
终端真实 PTY（vim / htop 等交互程序可用）

技能、智能体与 MCP 工具

  • 在输入框敲 / 唤起技能菜单；技能可以是内置的（翻译、总结、解释、润色），也可以是你自己写的提示模板，或磁盘上的 Markdown / JSON 技能文件。
  • 「智能体」页面管理系统提示预设：分类、搜索、工具白名单、逐工具审批策略，支持 JSON 导入导出。
  • MCP 服务器（设置 → MCP Server）连上后，其 tools/list 发现的工具会自动进入工具面，可直接被对话调用。
