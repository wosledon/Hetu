本地模型

Foundry Local 本地模型运行时：浏览模型目录、下载、加载与卸载，自定义模型保存路径，并一键接入 Hetu 的对话与知识库。

是什么

「本地模型」把 Foundry Local 这套本地推理运行时接进了 Hetu：不用 API Key、不联网，用自己机器上的 GPU/NPU 跑开源模型。它覆盖 foundry 命令行工具的主要能力面，对话、Code 会话、知识库分块与 Embedding 都能直接切到这些模型上。

入口：左侧导航「本地模型」（/foundry-local），默认在动态区关闭，去「设置 → 导航菜单」里打开即可固定显示。

运行状态

页面顶部一张状态卡，实时反映本地运行时：

字段说明
运行状态本地 OpenAI 兼容服务是否在监听；「启动服务 / 停止服务」对应 foundry service start/stop
服务端点形如 http://127.0.0.1:5272/v1。端口由运行时分配，不是固定的
已加载常驻内存的模型数（对应 foundry service ps），占显存/内存的正是这些
已下载本地有缓存的模型数（对应 foundry cache list）

模型保存路径

模型动辄数 GB，存放位置可以在页面里直接改：填一个绝对路径保存即可，重启 Hetu 后生效。

  • 默认路径是 Hetu 数据目录下的 foundry-models，与 SQLite、日志同一套优先级（Hetu:DataDir → HETU_DATA_DIR → 系统本地应用数据目录）
  • 「恢复默认」一键回到上述目录
  • 保存后需要重启 Hetu 才会切换：本地运行时是进程级单例，初始化后无法原地重建，页面会给出重启提示
  • 换路径不会自动迁移已下载的文件：想搬就在重启前把旧目录里的内容复制到新目录，或先删旧缓存再重新下载

模型目录

中间是模型目录列表，按「已下载 → 名称」排序，每条显示发布方、模型类型、上下文长度与体积。

操作说明
下载首次需要联网从模型源拉取，进度条实时推进；下完即落在上面的保存路径里
加载 / 卸载对应 foundry model load/unload。加载才真正占用显存，用完后卸载可立刻释放
删除删掉本地文件（对应 foundry cache remove），下次使用需重新下载
接入 Hetu一键把该变体注册成「Foundry Local」服务商下的对话模型，之后就能在对话与 Code 会话里选它

目录上方一排筛选下拉（选项与计数由目录数据自动生成）：任务类型、输入模态、设备（CPU / GPU / NPU）、是否支持工具调用、是否已下载；右侧可切换排序（名称 / 体积 / 上下文长度）。搜索框按别名、显示名、发布方与类型过滤。

关于「设备」筛选：目录按「模型 × 设备变体」平铺，同一个模型会有多行——例如 phi-4-mini 同时有 GPU（CUDA）、GPU（WebGPU）与 CPU 三行，体积各不相同（GPU 更小）。设备筛选项的计数由目录数据生成，当前为 GPU 71 / CPU 56。

页面顶部的「执行提供程序」卡片列出本机可用的 GPU/NPU 后端及注册状态，可一键下载注册——这是跑 GPU/NPU 变体的前提。已下载但所需 EP 未注册的变体，「加载」会变成「注册 XX」；本机压根没有该 EP 时（例如 AMD 显卡机器上没有 CUDA）会直接标注「本机无 XX」，不会让你白点。

接入 Hetu 大模型

点「接入 Hetu」会做两件事：创建一个 foundry 类型的服务商（没有 API Key，Base URL 填当前端点），再把该模型注册为对话模型。之后：

  • 在「设置 → 大模型」里可以把它设为默认对话模型，或改用途、调上下文长度等
  • Embedding 用途同理：把本地的 embedding 模型注册进来，知识库的向量索引就能全本地跑
  • 服务商也可以手工添加：类型选「Foundry Local（本地）」，Base URL 填运行时给出的端点——跨机器指向另一台机器上的 Foundry Local 时走这条路
本地服务重启后端口可能变化。如果对话时连不上，回本页看一眼当前端点，把服务商的 Base URL 更新成新值即可。

平台支持

Foundry Local 目前只支持 Windows（依赖 DirectML / WinML）。在 Linux 与 macOS 上入口仍在，但会整体置灰并说明原因；此时仍可通过手工添加 OpenAI 兼容服务商的方式，指向另一台 Windows 机器上的 Foundry Local 端点来使用。

数据与接口

管理面接口遵循统一响应约定，只读列表带短时响应缓存：

方法路径说明
GET/api/foundry-local/status运行状态、端点、保存路径、已加载/已下载数量
GET/api/foundry-local/models?cachedOnly=false模型目录（按模型 × 设备变体平铺）；cachedOnly=true 只看本地已有
GET/api/foundry-local/models/loaded当前常驻内存的模型
POST/api/foundry-local/models/{alias}/download下载；SSE 推进度帧 {alias, progress, state, error}
POST/api/foundry-local/models/{alias}/load / unload加载 / 卸载
POST/api/foundry-local/models/{alias}/register?purpose=chat注册为 Hetu 模型，返回模型 Id
DELETE/api/foundry-local/models/{alias}删除本地缓存
POST/api/foundry-local/service/start / stop启停本地 OpenAI 兼容服务
PUT/api/foundry-local/model-dir设置保存路径；传空恢复默认

模型本身走 OpenAI 兼容协议，由现有的 LLM / Embedding 工厂按 foundry 服务商类型分发，不引入第二套推理协议。
