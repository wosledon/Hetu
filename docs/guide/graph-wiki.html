知识图谱与 Wiki

两个把「零散内容」变成「结构化知识」的功能：图谱抽出实体与关系，Wiki 把项目资料写成成篇文档。

知识图谱

抽取流程

  1. 在笔记编辑器点「提取图谱」，或对已有内容重新抽取。
  2. LLM 从正文抽取实体（名称、类型）与关系（源实体、目标实体、关系类型），随后做去重与合并。
  3. 结果写入图谱表，同时生成一条后台任务记录（类型「知识图谱提取」），可查看耗时与状态。

实体与关系类型

实体类型说明
概念 / 技术 / 项目默认内置类型，界面按类型着色区分
人物 / 组织用于记录来源、团队、作者等
自定义抽取时模型可给出其他类型
关系类型语义
belongs-to属于（子概念 → 父概念 / 项目）
related-to相关（弱关联）
depends-on依赖
contains包含
compared-with对比（常用于选型笔记）
custom其他关系

可视化操作

操作说明
缩放 / 平移滚轮缩放、拖拽平移；提供重置视图按钮
搜索按实体名过滤高亮；侧栏可按类型筛选
查看详情点实体看它的关系列表与来源笔记，可直接跳回编辑器
统计顶部显示实体总数与关系总数，以及各类型计数

Wiki 生成

输入材料

  • 项目资料：README、目录结构、关键源码片段（按项目根目录扫描）。
  • 可选叠加语义检索：从已索引内容里补充与模块相关的片段。
  • 生成模型取「默认模型 → Wiki 生成」这一场景设置。

生成阶段

阶段产物
资料收集读取 README 与目录，挑选代表文件
模块页按模块生成多页文档（并发执行，可配置模块数上限与并发度）
总览页汇总项目简介、结构、快速开始等（标题取项目名，排序置顶）
落库一次生成 = 一个套件（SetId），页面带排序号

整个过程是后台任务（类型 WikiGenerate），阶段与进度记录在任务里；失败时任务详情给出原因，可重跑。

浏览

  • Wiki 页按套件分组：套件头显示项目名、生成时间、页数；「有更新」表示项目资料在生成后有变动。
  • 套件内按排序展示：总览在前，其后是各模块页。
  • 可在项目卡片上直接发起生成，生成完在 Wiki 页查看。
