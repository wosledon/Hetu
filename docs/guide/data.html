数据与备份

Hetu 把「数据主权」当作前提：默认单文件数据库、可整体搬迁、随时导出，不需要任何云端账号。

数据目录

运行方式位置
桌面版（Windows）%LOCALAPPDATA%\Hetu
源码运行由 HETU_DATA_DIR 指定；不设时用工作目录下的 hetu.db
数据库文件hetu.db（+ -wal / -shm）
日志logs/（Serilog，按天滚动）

导出与备份

  • 设置 → 数据与备份：把全部笔记导出为 Markdown 压缩包；备份 / 恢复 SQLite 数据库文件。
  • 跨机器迁移：关闭应用后整体拷贝数据目录（含 hetu.db 与其 WAL 文件），在新机器打开即可。
数据库运行时用文件级拷贝做备份，可能丢掉尚未 checkpoint 的 WAL 内容。稳妥做法是在应用内退出后拷贝，或用内置的备份功能。

切换到 PostgreSQL

需要 PostgreSQL 16+ 并安装 pgvector 扩展：

export DatabaseProvider=Postgresql
export ConnectionStrings__DefaultConnection="Host=localhost;Database=hetu;Username=postgres;******"

# 应用迁移（表结构变化时需要）
dotnet ef database update \
  --project src/Hetu.Infrastructure.PostgresMigrations \
  --startup-project src/Hetu.Api

向量维度由 Embedding:Dimensions 决定，必须与所选 Embedding 模型一致。SQLite 与 PostgreSQL 的功能集一致，切换后原有笔记与索引需在新的库里重建。

向量存储

数据库向量方案说明
SQLitesqlite-vec（vec0.dll / vec0.so）随应用分发，连接打开时自动加载，无需额外安装
PostgreSQLpgvector需先启用扩展；维度与配置一致

隐私与安全

  • 本地优先：没有账号体系、没有遥测上报；除你配置的模型供应商与主动开启的联网搜索 / MCP 服务外，应用不主动外发数据。
  • Key 加密：API Key 使用 ASP.NET DataProtection 加密存储（Windows 走 DPAPI），日志与接口响应都不含明文。
  • 渲染安全：Markdown 渲染经 DOMPurify 过滤，避免笔记内容注入脚本。
  • 命令执行有闸门：工具执行受权限模式约束（见 Agent 工作台），高风险动作默认需要确认。
  • 分享链接：生成的公开链接只暴露那一篇笔记的渲染结果，可随时停用，并带访问计数。
