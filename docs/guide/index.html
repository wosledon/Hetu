卡住了？

先看 常见问题：安装失败、端口占用、索引不动、工作树清理、更新报错都在那里。要定位后端问题，先确认 http://localhost:5000/api/health 是否正常，再看数据目录下的 logs/。

文档与代码同步维护；如果发现页面与实现不一致，欢迎在 GitHub Issues 指出具体页面与段落。
