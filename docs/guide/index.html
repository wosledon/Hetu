Hetu 文档

Hetu（河图）是本地优先的 AI 知识与 Agent 工作台：笔记、对话与编码会话共用一套底座，向量检索、知识图谱、Wiki、记忆、任务与工作流把它们连成一张活的网络。

第一次用建议按顺序读：快速开始 → 功能总览 → Agent 工作台；只想部署到自己的机器，直接看 桌面应用 与 数据与备份。

它解决什么问题

你现在的状态Hetu 的做法
笔记散在多个工具里，搜不到、连不起来一套本地库承载笔记 + 对话 + 代码会话，向量检索与知识图谱把内容连起来
AI 聊天记录看完就丢话题可整理成笔记、抽成记忆、生成 Wiki，产物直接落库
AI 写的代码需要自己复制粘贴Code 会话在真实仓库里动手：工作树隔离、逐行 Diff、检查点回滚、PR 创建
担心数据和 Key 上云完全本地运行，无账号无遥测，Key 加密存储
