文档索引

Hetu 是本地优先的 AI 知识与 Agent 工作台。文档按功能域分页，每页包含该功能的操作路径、配置项、数据落点与常见排错。

第一次使用按 快速开始 → 笔记 → Agent 工作台 → Code 会话 读；关心实现细节直接看 架构与实现。
