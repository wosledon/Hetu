快速开始

三种起步方式：下载桌面版（最省事）、源码跑起来（要改代码）、Docker？暂时没有——本项目就是「本地优先」，直接跑在本机最合适。

方式一：桌面版（推荐先用这个）

到 Releases 下载对应安装包：

渠道文件说明
fatHetu_x.y.z_x64-setup.exe自带 .NET 运行时，装完即用（体积大些）
slimHetu.Slim._x.y.z_x64-setup.exe体积小，需要机器上已安装 .NET 10 运行时
Linux.AppImage / .debAppImage 直接 chmod +x 后运行
桌面版关闭窗口默认最小化到托盘（后端继续跑，后台任务不断），要真正退出请用托盘菜单「退出 Hetu」。该行为可在 设置 → 应用设置 关闭。

方式二：源码运行

需要 .NET SDK 10.0+ 与 Node.js 20+。

git clone https://github.com/wosledon/Hetu
cd Hetu

# 一键启动前后端（Windows / Linux / macOS 都有脚本）
pwsh ./scripts/start.ps1        # Windows
./scripts/start.sh              # Linux / macOS

# 或者分别启动
dotnet run --project src/Hetu.Api --urls "http://localhost:5000"
cd frontend && npm install && npm run dev

打开 http://localhost:5174 即可。后端接口文档在 http://localhost:5000/scalar/v1，健康检查 /api/health。

方式三：桌面开发模式

要改桌面外壳（Rust）或联调 sidecar 时使用，会并行起 dotnet + vite + tauri：

pwsh ./scripts/desktop-dev.ps1

第一次配置

  1. 加供应商：左侧「大模型」→ 新增供应商（OpenAI 兼容 / Anthropic），填 Base URL 与 API Key。
  2. 加模型：在供应商下新增模型，用途选 chat；要做语义检索再添一个 embedding 模型。
  3. 设默认：设置 → 默认模型，按场景指定（对话、编码、Wiki、图谱、整理、笔记 AI）。
  4. 喂知识：写一篇笔记，或到「知识库」添加网址 / 上传文件，然后点「生成索引」。
  5. 试一下：工作台里问一句需要引用你笔记的问题，输入框上方打开「知识库」开关。

接下来

  • 想让它替你改代码：Agent 工作台（工作树、权限模式、PR）。
  • 想把资料变成可检索的知识：知识底座（索引、图谱、Wiki、记忆）。
  • 想知道花了多少 Token：模型与用量。
