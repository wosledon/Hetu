快速开始

三条路：下载桌面版、从源码运行，或进入桌面开发模式。第一次启动后大约五分钟可以完成配置。

第一次使用建议按这个顺序：安装 → 加供应商 → 加模型 → 设默认模型 → 写一条笔记并生成索引。只想先看看界面的话，安装完直接打开 Code 页即可。

0. 你需要什么

场景要求
桌面版 fatWindows 10/11 x64 或主流 Linux 发行版；无需预装 .NET
桌面版 slim同上，但需要系统已安装 .NET 10 运行时
源码运行.NET SDK 10.0+、Node.js 20+、Git
模型OpenAI 兼容或 Anthropic 协议的 API Key；也可以接本地推理服务

1. 安装桌面版

到 GitHub Releases 下载对应安装包：

渠道产物说明
fatHetu_x.y.z_x64-setup.exe / .msi自带 .NET 10 运行时，装完即用，体积较大
slimHetu (Slim)_x.y.z_x64-setup.exe / .msi需要系统 .NET 10 运行时，体积小
Linux.AppImage / .debAppImage 下载后需要 chmod +x
fat 与 slim 是两条独立的更新流：装 slim 只会收到 slim 的更新清单，不会被 fat 覆盖。

关闭主窗口默认最小化到托盘，后端与后台任务继续运行；要真正退出请用托盘菜单「退出 Hetu」。这个行为可以在 设置 → 应用设置 中关闭。

2. 第一次配置

步骤位置要点
加供应商大模型 → 新增供应商选择 OpenAI 兼容或 Anthropic；填 Base URL 与 API Key
加模型供应商下的模型列表用途分为 chat / embedding / completion
设默认设置 → 默认模型按场景指定：对话、编码、Wiki、图谱、整理、笔记 AI、查询改写
喂知识知识库添加网址或上传文件；笔记在编辑器顶部点「生成索引」
试一下Code 页输入问题时打开输入框上方的「知识库」开关，引用检索结果
Anthropic 没有公开 Embedding 接口，embedding 用途请选 OpenAI 兼容供应商。向量维度必须与模型一致（Embedding:Dimensions，默认 1536），不一致时写入会失败。

3. 从源码运行

git clone https://github.com/wosledon/Hetu
cd Hetu

pwsh ./scripts/start.ps1        # Windows：一键起前后端
./scripts/start.sh              # Linux / macOS

# 分开启动
dotnet run --project src/Hetu.Api --urls "http://localhost:5000"
cd frontend && npm install && npm run dev   # http://localhost:5174
地址用途
http://localhost:5174前端界面
http://localhost:5000/api后端接口
http://localhost:5000/scalar/v1接口文档（Scalar）
http://localhost:5000/api/health健康检查；桌面壳用它判断后端是否就绪

确认后端正常：

curl http://localhost:5000/api/health

4. 桌面开发模式

需要改 Rust 外壳、托盘、更新逻辑或联调 sidecar 时，用桌面开发模式并行启动 dotnet、Vite 与 Tauri：

pwsh ./scripts/desktop-dev.ps1

开发期如果 5000 端口已经有后端在跑，Tauri 会直接复用，避免和你自己启动的 dotnet run 冲突。

5. 数据在哪里

运行方式位置
桌面版（Windows）%LOCALAPPDATA%\Hetu：hetu.db 与 WAL、logs/
源码运行由 HETU_DATA_DIR 指定；未设置时是工作目录下的 hetu.db
备份 / 迁移退出应用后整目录拷贝即可；数据库与日志都在同一处

遇到问题

现象先检查
前端打不开5174 端口是否被占用；终端里 Vite 是否报错退出
接口 500 / 无法连接/api/health 是否响应；5000 端口是否被其它进程占用
索引不动知识库页的索引进度、Embedding 模型是否可用、维度是否一致
安装时提示文件被占用先退出托盘中的 Hetu；残留的 Hetu.Api.exe 会锁住 vec0.dll

更多错误与处理方式见 常见问题；需要看实现细节时从 架构与实现 进入。
