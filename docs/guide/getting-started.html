快速开始

三种运行方式：桌面安装包（最省事）、源码运行（要改代码）、桌面开发模式（改 Rust 外壳或联调 sidecar）。

方式一：桌面安装包

到 Releases 下载：

渠道Windows 产物依赖与体积
fatHetu_x.y.z_x64-setup.exe / .msi自带 .NET 10 运行时，装完即用，约 100 MB+
slimHetu.Slim._x.y.z_x64-setup.exe / .msi需系统已安装 .NET 10 运行时，体积小
Linux.AppImage / .debAppImage 需要 chmod +x
两个渠道是相互独立的更新流：装 slim 只会收到 slim 的更新清单，不会把 fat 版覆盖上去。

关闭窗口默认最小化到托盘（后端继续跑，后台任务不中断）；要真正退出用托盘菜单「退出 Hetu」。该行为可在 设置 → 应用设置 关闭。

方式二：源码运行

git clone https://github.com/wosledon/Hetu
cd Hetu

pwsh ./scripts/start.ps1        # Windows：一键起前后端
./scripts/start.sh              # Linux / macOS

# 分开启动
dotnet run --project src/Hetu.Api --urls "http://localhost:5000"
cd frontend && npm install && npm run dev   # http://localhost:5174
地址用途
http://localhost:5174前端界面
http://localhost:5000/api后端接口
http://localhost:5000/scalar/v1接口文档（Scalar）
http://localhost:5000/api/health健康检查（桌面壳用它判断就绪）

方式三：桌面开发模式

并行启动 dotnet + vite + tauri，用于改 Rust 外壳、托盘、更新逻辑或联调 sidecar：

pwsh ./scripts/desktop-dev.ps1

开发期若 5000 端口已有后端，Tauri 会直接复用，避免和你自己跑的 dotnet run 冲突。

第一次配置

步骤位置要点
加供应商大模型 → 新增供应商协议选 OpenAI 兼容或 Anthropic；填 Base URL 与 API Key（本地推理服务同样适用）
加模型供应商下的模型列表用途 chat / embedding / completion
设默认设置 → 默认模型按场景指定（对话、编码、Wiki、图谱、整理、笔记 AI、查询改写）
喂知识知识库添加网址 / 上传文件；笔记在编辑器顶部点「生成索引」
试一下Code 页输入问题时打开输入框上方的「知识库」开关即可引用检索结果
Anthropic 没有公开 Embedding 接口，embedding 用途请选 OpenAI 兼容供应商。向量维度必须与模型一致（Embedding:Dimensions，默认 1536）。

数据落在哪

运行方式位置
桌面版（Windows）%LOCALAPPDATA%\Hetu：hetu.db + WAL、logs/
源码运行由 HETU_DATA_DIR 指定；未设置时是工作目录下的 hetu.db
