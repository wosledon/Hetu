笔记

入口是左侧导航「笔记」（路由 /）。三栏结构：笔记本树 / 笔记列表 / 编辑器。

编辑器

项说明
编辑模式所见即所得（Milkdown：标题、列表、表格、代码块、数学公式 KaTeX、Mermaid 图、图片、任务列表）与源码模式（CodeMirror，Markdown 高亮）切换，支持分屏
自动保存停止输入约 3 秒后保存，标题栏显示草稿 / 已保存状态；Ctrl+S 可立即保存
图片粘贴 / 拖入即上传到附件目录并插入引用
预览渲染Mermaid、KaTeX、GFM 表格与任务列表；输出经 DOMPurify 过滤

AI 写作

  • 选区动作：选中文字后浮动菜单提供润色、翻译、精简、扩写、解释、自定义提示；结果可替换选区或插入到下方。
  • 笔记助手：整篇笔记级别的对话面板，可按次指定模型（不受默认模型限制），适合「把这节改写成要点」这类整篇操作。
  • 笔记内动作：编辑器顶部按钮——生成知识库索引、提取知识图谱、生成标签、生成流程图（Mermaid 代码块），都会以后台任务形式执行并在完成后回填。

笔记本与标签

功能操作
笔记本无限层级；新建、重命名、删除、右键菜单；未归档笔记落在「未分类」
标签独立页面 /tags 管理：配色、重命名、合并；笔记页侧栏可按标签筛选
置顶 / 收藏列表置顶优先排序，其次是最近更新时间（排序在数据库完成，分页稳定）
搜索笔记列表顶部搜索框；按标题与内容匹配

历史版本

  • 每次内容变更自动生成快照，按笔记保留最近 20 个版本（超出部分在数据库侧用一条 DELETE 清理）。
  • 可预览任意版本、查看差异、一键还原；还原前会把当前内容先存为一个新版本。

分享链接

  • 为单篇笔记生成公开只读链接，有效期可选永久 / 24 小时 / 3 天。
  • 记录访问次数，可随时停用；公开页路由是 /share/:code，只渲染那一篇笔记，不暴露其他数据。

回收站与导出

  • 回收站（/trash）：软删除笔记的恢复与彻底删除；默认保留 30 天后清理。
  • 导出：设置 → 数据与备份可把全部笔记导出为 Markdown 压缩包，也可备份 / 恢复数据库文件。详见 数据与安全。
