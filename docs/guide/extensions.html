扩展与集成

四项功能决定 Agent 能做什么、用什么身份做、能调用哪些外部工具。

智能体（提示预设）

入口：/agents。一个智能体 = 系统提示 + 模型偏好 + 工具白名单 + 逐工具审批策略。

项说明
分类与搜索按用途分组（编程、写作、分析…），支持搜索
工具白名单只允许指定工具，降低越权操作风险
审批策略每个工具单独设置：静默 / 自动 / 询问
导入导出JSON 形式导入导出全部智能体，便于备份与分享

技能

入口：/skills。技能 = 一段可复用的提示模板，对话里用 /技能名 调用。

来源说明
内置技能翻译、总结、解释、润色等开箱可用
自定义技能自己写提示模板与系统提示，可在页面直接试跑预览输出
磁盘技能目录从配置的目录加载 Markdown / JSON 技能文件，适合团队共享或用 Git 管理

工具

入口：/tools。内置工具可按需开关，关闭后模型无法调用。

工具用途
笔记检索 / 读取 / 创建 / 更新在对话里读写笔记，支持按条件搜索
联网搜索需要外部信息时检索网页
记忆检索 / 创建查询与写入长期记忆
图谱检索按实体与关系查询知识图谱
待办清单输出结构化计划并实时勾选
命令执行在项目工作区里执行命令（受权限模式约束）
文件操作列目录、读、写、移动、删除
提问需要用户决策时发起交互式提问

MCP 服务器

入口：设置 → MCP Server。支持把外部 Model Context Protocol 服务的工具接进来。

项说明
传输stdio：启动子进程并用 JSON-RPC 2.0 通信（完整支持）；sse：可配置，未接线
连接配置JSON：command / args / env（stdio）或 url（sse）
工具发现调用 tools/list 拉取工具清单，自动并入对话工具面
工具调用调用 tools/call，参数与结果在消息流里结构化展示
启停逐服务器启用 / 禁用，可排序
MCP 工具与内置工具共用同一套权限模式与审批策略；不确定行为的服务建议先用「询问」模式跑一遍。

配置示例

MCP 服务器（stdio）

{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "E:\\repos"],
  "env": { "NODE_ENV": "production" }
}

技能文件（磁盘目录）

---
name: code-review
description: 按固定清单审查改动
---
请按以下顺序审查选中的代码：
1. 正确性与边界条件
2. 资源释放与并发
3. 命名与可读性
4. 与该模块既有风格的一致性

技能目录在设置里配置后可被扫描加载；同名技能以磁盘版本为准。

智能体（导入导出 JSON）

{
  "name": "代码审查员",
  "category": "coding",
  "systemPrompt": "只指出真实缺陷，附最小复现与修复建议。",
  "allowedTools": ["read_file", "search_code", "run_command"],
  "toolPolicies": { "run_command": "ask", "update_note": "silent" }
}

应用（内嵌浏览器）

入口：/apps。把常用网页登记为「应用」，用应用内浏览器打开，避免来回切窗口。

项说明
登记名称 + URL（本地服务如 http://localhost:5174 或外站）
打开应用内嵌视图，带地址栏、前进后退、刷新与常用链接
超时提示目标站点用 X-Frame-Options / CSP 拒绝内嵌时，4 秒后提示改用系统浏览器打开
