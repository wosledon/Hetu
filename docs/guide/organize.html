看板与自动化

把「要 AI 做的事」变成可跟踪的工作项：任务看板、工作流、后台任务与定时任务、收件箱。

任务看板

入口：左侧导航「任务看板」（/kanban）；详情页 /kanban/:taskId。

列含义
进行中已被 Agent 接手、正在执行
审核中Agent 完成，等待你确认结果
已阻塞缺信息或执行失败，需要人工介入
已完成已确认完成
已归档历史任务（可按时间范围筛选）
任务字段说明
标题 / 描述要做什么；描述越具体，Agent 执行越稳
指派智能体选择某个系统提示预设（可带工具白名单与审批策略）
优先级 / 分类用于看板筛选与排序
运行记录每次执行的步骤列表（每一步的动作、耗时、输出摘要）
评论人机协作的讨论线程，Agent 执行时会参考

执行同样受权限模式与后台任务系统约束：一次执行会创建一条 KanbanTaskExecute 后台任务，失败可在任务详情看到原因。

工作流

入口：/workflows。把多步 Agent 任务画成流程，适合「先调研再实现再自测」这类固定套路。

项说明
节点每个节点是一次 Agent 任务，可配置提示、智能体与依赖关系
启停工作流可整体启用 / 禁用，便于保留草稿
运行每次运行记录节点状态、耗时与产物，可在界面查看运行历史

后台任务

入口：/tasks/background。所有长耗时操作都进这个队列并留下记录，可查状态、耗时与失败原因。

任务类型触发来源
生成 Embedding笔记索引、批量补索引
生成知识项 Embedding文件 / 网址索引
知识图谱提取笔记的「提取图谱」
Wiki 生成项目页 / Wiki 页发起
看板任务执行任务看板指派 Agent
工作流运行工作流执行

任务状态：排队 / 运行中 / 已完成 / 失败；列表可按类型筛选、清理已完成、逐条删除。存在运行中任务时页面自动轮询刷新。

定时任务

入口：/tasks/scheduled。用 Cron 表达式安排周期性动作（例如每晚整理收件箱、定期跑 Dream、定时生成 Wiki），可查最近几次执行结果。

收件箱

入口：/inbox，导航栏带未读角标。用于汇总需要你关注的事（任务失败、需要审批、系统提示等），支持已读 / 未读、归档与按类别筛选。
