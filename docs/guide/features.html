功能总览

Hetu 的界面由「笔记」和「Agent 工作台」两个主入口，加上一组知识底座与自动化页面组成。下面是每块能力与对应路由的索引。

页面地图

路由页面能做什么
/笔记笔记本树、笔记列表、Markdown 编辑器、历史版本、分享
/codeAgent 工作台对话与 Code 会话（/chat、/work 也跳到这里）
/projects项目本地 / SSH 仓库与分组，生成 Wiki
/kanban任务看板五列看板，任务可指派 Agent 执行
/wikiWiki按套件浏览生成的文档

/memories记忆长期记忆、记忆图、Dream 巩固与遗忘
/tasks/*后台 / 定时任务任务状态与耗时、Cron 定时任务
/workflows工作流可视化编排 Agent 多步骤流程

笔记

  • 双视图编辑：Milkdown 所见即所得 + CodeMirror 源码视图，编辑 / 预览 / 分屏。
  • AI 写作：选中文字即可润色、翻译、精简、扩写、解释或自定义提示；整篇笔记的 AI 助手面板可按次换模型。
  • 笔记内 AI 动作：生成知识库索引、提取图谱、自动打标签、生成流程图（Mermaid）。
  • 组织：无限层级笔记本、带颜色的标签（可重命名/合并）、置顶与收藏。
  • 安全网：3 秒自动保存、历史版本快照（预览 / 对比 / 一键还原）、回收站、Markdown 导出与数据库备份。
  • 分享：为单篇笔记生成永久 / 24 小时 / 3 天链接，带访问计数，公开只读页 /share/:code。

Agent 工作台

对话与编码会话共用一套交互：会话树、消息流、输入工具带。细节见 Agent 工作台。

  • 流式与过程可见：正文增量、思考轨迹、工具调用与结果、联网搜索结果、知识库与记忆命中、检查点、审批请求。
  • 能打断也能排队：回复进行中继续输入会进队列（可编辑/删除/立即发送），或点「引导」把新指令插进当前这一轮。
  • 权限五档：计划 / 只读 / 询问 / 自动 / 绕过；Code 会话另有交互式与 Autopilot 运行模式。
  • 整理成笔记：把话题蒸馏为摘要 / 详细 / 问答 / 自定义格式的笔记，带流式预览。

知识底座

  • 知识库：笔记、文件、网址统一分块向量化，看覆盖率、分块数、维度，可重新索引。
  • 知识图谱：AI 从笔记抽取实体与关系并去重，力导向可视化，点实体看关联笔记。
  • Wiki 生成：按项目生成模块页 + 总览，按套件分组，保留生成时间与更新状态。
  • 记忆与 Dream：长期记忆配类别与重要性，按衰退/遗忘天数定期巩固、衰减、遗忘。

组织与自动化

  • 任务看板：进行中 / 审核中 / 已阻塞 / 已完成 / 已归档；任务可指派智能体执行，记录步骤、评论与产物。
  • 工作流：把多步 Agent 任务画成流程，支持启停与运行记录。
  • 后台与定时任务：索引、图谱、Wiki 等长任务的进度、耗时、失败原因；支持 Cron 计划任务。
  • 收件箱：统一通知中心，导航栏带未读角标。
  • 应用：把常用网页（本地服务或外站）登记进来，用内置浏览器直接打开。

扩展与模型

  • 智能体：系统提示预设，带工具白名单与逐工具审批策略，可 JSON 导入导出。
  • 技能：内置技能 + 自定义技能，也能从磁盘目录加载 Markdown / JSON 技能文件；对话里用 /技能名 调用。
  • 工具：笔记读写与搜索、联网搜索、记忆与图谱检索、待办、命令执行、文件操作等，可逐项开关。
  • MCP：管理 Model Context Protocol 服务器（stdio 完整支持，sse 可配置），自动发现并调用工具。
  • 模型与用量：多供应商多模型、按场景默认、兼容代理接口、Token 与成本统计。
