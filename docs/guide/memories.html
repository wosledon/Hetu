记忆与 Dream

记忆解决「跨会话的长期上下文」：偏好、身份、工作习惯、固定事实。入口：左侧导航「记忆」（路由 /memories）。

记忆条目

字段说明
内容一句话事实或偏好，越具体召回越准
类别偏好 / 身份 / 工作 / 习惯 / 知识等，用于筛选与统计
重要性1–5 星，影响召回排序与衰减速度
作用域全局 / 会话 / 项目：决定在什么上下文里会被注入
生命周期最近访问时间、访问次数、状态（新鲜 / 衰退中）由 Dream 维护

召回时机

  • 对话输入框的「记忆」开关：按当前作用域（全局 ∪ 当前会话 ∪ 当前项目）做相似度召回并注入。
  • 模型可主动调用 search_memory 工具查询。
  • 作用域隔离的意义：项目细节不会被带进无关的对话，会话级偏好不会污染全局。

记忆图

  • 把记忆按关联度可视化，便于发现重复或矛盾的条目。
  • 可按作用域筛选（全部 / 全局 / 会话 / 项目），悬停查看内容。

Dream 巩固

参数作用
衰退天数超过该天数未被访问的记忆进入「衰退中」
遗忘天数超过该天数未被访问且重要性低的记忆会被遗忘（删除）
运行间隔自动巩固周期，默认每 24 小时一次，可在设置里调整
阶段合并重复记忆 → 衰减过时信息 → 遗忘无用条目，最后给出统计

页面显示上次运行时间与「正在衰退」条数，可手动触发一次巩固；执行结果会给出合并 / 衰减 / 遗忘 / 剩余数量。

实践建议

  • 把稳定的偏好写成全局记忆（「回答用中文，代码注释用英文」）。
  • 项目相关的约定写成项目记忆，跟着项目上下文走。
  • 一次只记一条事实，便于后续合并与遗忘；长篇内容更适合写成笔记再索引。
