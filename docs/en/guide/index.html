From first launch to the agent loop.

Hetu docs are organised as “use it → understand it”: get notes and Code sessions working first, then read how retrieval, compression, permissions and workflows are built. Every page covers the UI path, configuration, where data lands and how to troubleshoot.

Stuck?

Start with FAQ: install failures, port conflicts, indexing stalls, worktree cleanup and update errors live there. To diagnose the backend, check http://localhost:5000/api/health first, then the logs/ directory under your data folder.
