How it works

Settle. Connect. Act.

Not another chat box, but a network that grows: every note, question and change becomes context for the next piece of work.

01

Settle

Keep notes, files, web pages and conversations on your machine. No account, no cloud copy, and a data directory you control.

02

Connect

Chunks, vectors, entities, relations, Wiki pages and memories are indexed automatically, so the next question finds the last context.

03

Act

Agents search, call tools, edit repositories and run tasks on the same base. Every step is recorded, reviewable and reversible.

Privacy

Your machine
is the server.

Hetu needs no account, uploads nothing and collects no telemetry. The SQLite database, vector index, keys and logs live on your disk; model requests only go to the providers you configure.

Data & security
  • Local data. SQLite + sqlite-vec works out of the box; switch to self-hosted PostgreSQL + pgvector when you need it.
  • Encrypted keys. API keys are encrypted at rest with DataProtection (DPAPI on Windows).
  • Controlled requests. Model providers, MCP servers and web search are enabled explicitly by you.
  • Transparent sources. This site only fetches the latest version number and anonymous visit counts — no cookies, no content.

Five minutes from install to first note.

The desktop build is the easy path; run from source if you want to change the code. Both have full setup and data-directory docs.

Desktop app

Recommended

Installers for Windows and Linux. Closing the window leaves Hetu in the tray, with the backend and background jobs still running.

# Windows: Hetu_x.y.z_x64-setup.exe / .msi
# Linux:   .AppImage / .deb

Run from source

Developers

Requires .NET SDK 10.0+ and Node.js 20+. The frontend runs on 5174 and the API on 5000.

git clone https://github.com/wosledon/Hetu
cd Hetu

pwsh ./scripts/start.ps1   # Windows
./scripts/start.sh         # Linux / macOS
