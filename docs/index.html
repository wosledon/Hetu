工作方式

沉淀、连接、行动。

不是又一个聊天框，而是一张会生长的网：每一次记录、提问和改动，都会成为下一次工作的上下文。

01

沉淀

把笔记、文件、网页和一次对话留在本地。没有账号，没有云端副本，数据目录由你掌控。

02

连接

分块、向量、实体、关系、Wiki 与记忆自动建立索引，让下一次提问找到上一次的上下文。

03

行动

Agent 在同一个底座上检索、调用工具、修改仓库、执行任务；每一步都有记录，可回看、可回滚。

隐私

你的机器，
就是服务器。

Hetu 不需要账号，不上传内容，不做遥测。SQLite 数据库、向量索引、密钥和日志都在你的磁盘上；模型请求只发往你配置的供应商。

数据与安全
  • 数据本地。SQLite + sqlite-vec 开箱即用，也可以切到自建 PostgreSQL + pgvector。
  • 密钥加密。API Key 由 DataProtection 加密落库，Windows 上走 DPAPI。
  • 请求可控。模型供应商、MCP 与联网搜索都由你显式启用。
  • 来源透明。本站只读取最新版本号与匿名访问计数，两者都不带 Cookie、不含内容。

./scripts/start.sh         # Linux / macOS
