汇成一处的知识工作台

Hetu（河图）把 Markdown 笔记、AI 对话和真正能动手的 Code 会话放在同一套底座上：向量检索、知识图谱、Wiki、长期记忆、任务与工作流把它们连成一张活的网络。所有数据与模型调用都在你自己机器上。

两个引擎，一层底座

写、问、做，最后都回到同一份知识

不是拼起来的一堆工具：笔记随时可被检索、索引、抽取图谱；对话与 Code 会话的产物（文件、检查点、记忆、Wiki）也直接落回同一个库。

笔记

所见即所得 Markdown + 源码视图，选中即 AI 润色/翻译/扩写；笔记本、标签、历史版本、分享链接、回收站、导出备份。

Agent 工作台

会话与话题、SSE 流式、深度思考、技能/智能体/MCP 工具带、五档权限模式；回复中还能排队与运行中引导。

Code 会话

本地或 SSH 仓库、独立工作树、本地+远程分支、Git 同步，文件/更改/检查点/Git/PR/浏览器/终端七个面板。

知识底座

笔记、文件、网址统一分块向量化；知识图谱抽取实体与关系；Wiki 生成；长期记忆配 Dream 巩固与遗忘。

组织与自动化

任务看板交给 Agent 执行、可视化工作流编排、后台与 Cron 定时任务、收件箱统一通知。

本地优先

无账号、无遥测，API Key 加密存储；桌面版自带托盘、双渠道安装包与镜像回退的自动更新。

源码运行 / 桌面安装

需要 .NET 10 SDK 与 Node.js 20+；不想装环境就直接下桌面版（fat 自带运行时，slim 需系统 .NET 10）。

一键启动（源码）

git clone https://github.com/wosledon/Hetu
cd Hetu

# Windows
pwsh ./scripts/start.ps1

# Linux / macOS
./scripts/start.sh

默认前端 http://localhost:5174，后端 http://localhost:5000，接口文档 /scalar/v1。

桌面版

# 下载安装包（Windows NSIS/MSI、Linux AppImage/deb）
# https://github.com/wosledon/Hetu/releases/latest

# 或者自己打包
pwsh ./scripts/publish-backend.ps1 -Mode SelfContained -Rid win-x64
cd shell/hetu-desktop && npm run tauri:build

桌面版带系统托盘、双渠道更新与镜像回退，数据落在系统用户数据目录。

工程取向

几条不打折的原则

你的数据不出本机

没有账号体系与遥测；模型调用只发往你自己配置的供应商，API Key 用 DataProtection 加密落库。

Agent 动手前先问过你

从只读、计划到自动执行五档权限；高风险命令走审批，改动进检查点，随时回滚。

零告警的代码库

后端 dotnet build 与前端 eslint 都不允许留告警，也不接受任何抑制注释——只能修根因。
