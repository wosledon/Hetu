# Hetu 0.3.47

本次更新把主题系统真正贯通到全站，并集中重做了组件边界、设置页、任务与对话体验。

## 主题与外观
- 新增「区域配色」：经典 / 晨雾 / 暖沙 / 苔原 / 暮紫 / 石墨；按导航 → 次级栏 → 列表栏 → 内容区四级色阶着色，亮暗各一套
- 新增「跟随区域」画布：直接取当前区域配色的列表栏色，切换配色时内容区同步变化
- 全站输入框、下拉、卡片、软面板、Markdown 代码块与对话组件统一跟随区域配色；弹窗 / 下拉 / 菜单使用每套配色的近不透明色，亚克力开关下都能保证可读
- 修复关闭亚克力时软件背景被外壳遮住、局部 `.dark` 容器重置区域变量等问题

## 界面与组件
- 组件边界收敛：原生控件与第三方库调用收口到共享封装，新增组件页 `/components`
- 工作台骨架统一：次级栏 256px、列表栏 320px；卡片、胶囊圆角与页面骨架统一
- 设置页改为工作台双栏；后台任务页重做（状态胶囊、类型筛选、骨架加载与实时指示）
- 新建任务弹窗改为双栏编辑器，支持图标 / 分组下拉与按类别选择自动处理
- 笔记搜索重做；主对话修复助手消息多余边框、执行过程摘要与对齐
- 本地模型环境检测增加加载态，不再先闪「未安装」
